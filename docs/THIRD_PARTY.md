# 第三方组件与 AI 使用说明

系统由 Codex 辅助实现；方案依据团队提供的 CareCircle 概念 PPT。未生成或冒充真实访谈、用户试点数据或第三方背书。

运行依赖及精确版本见 backend/composer.lock、backend/package-lock.json、mobile/pubspec.lock。包含 Laravel、Filament、Sanctum、Flutter、Riverpod、Dio、go_router、flutter_secure_storage。许可证以各上游包内 LICENSE 和声明为准。

网页和视频中使用 GSAP。已安装包声明为 Standard 'no charge' license，官方条款：https://gsap.com/standard-license/ 。不要误标成 MIT。

视频使用自行录制的本地 Android 模拟器与本地管理后台画面。所有身份、地址和任务均为虚构测试资料。影片使用无声操作演示及人工编排的中文说明字幕，没有合成受访者或虚构调研引语。

中文字体 Noto Sans SC 来源：https://github.com/google/fonts/tree/main/ofl/notosanssc ，按 SIL Open Font License 使用，许可文件与字体一同放在视频工程 assets/fonts/OFL.txt。

视频字幕入场采用 HyperFrames registry 的 staggered-fade-up 组件配方。视频工程保留安装组件及引用信息。
