## 重要边界

- 所有身份、地址、审核依据、任务和处理结果均为虚构演示资料；没有真实居民访谈、社区试点或影响评估。
- 验证发生在本地与 Android 模拟器。没有物理 Android／iPhone 验证、公开部署、商店上架或生产运行证据。
- iOS 只做模拟器构建验证，不声称已完成签名、安装或真机测试。
- Android APK 采用开发签名、arm64 架构，默认访问 Android 模拟器的主机回环 API。真实设备使用前需配置可达的 HTTPS 服务地址并重新构建。
- 通知为站内消息及前台刷新，没有后台推送。志愿者身份与授权由管理员人工核验，没有连接外部身份数据库。
- 确认码证明一次交接确认动作，不保证物品质量或人身安全。
- 本地开发配置不代表生产安全部署配置。上线前还需要真实运营方、授权流程、服务条款、生产密钥、HTTPS、备份及真实设备验收。

## 发现并修正的问题

- 不同交接操作共享限流计数：改为独立限流策略。
- 审核后读取旧志愿者状态：以当前数据库资格重新校验。
- 家属撤销后列表仍可能带出联系方式：显式限制序列化字段。
- Flutter ListTile 背景及点击反馈断言：统一使用 Material 承载。
- 退出时缓存失效形成循环依赖：改为账号身份驱动的数据刷新，并加入回归测试。
- 连接失败被自动重试长期隐藏：请求 Provider 改为明确显示错误并由用户重试，真实连接恢复测试通过。
- 原始目录的隐藏字符使 Flutter LSP 崩溃：保留原入口符号链接，以 ASCII 实际目录运行工具。

启动脚本已检查：独立进程启动、跨工具调用后的健康检查、重复启动不重复创建进程。队列和调度均保留运行。视频预览 HTTP 200，动画图谱已生成并核对 142.4 秒时间线。

交付 APK 通过 `adb install -r` 安装返回 Success，并以 `am start -W` 冷启动返回 Status: ok；发布版登录画面截图已检查。影片实际为无音轨输出，符合无声演示设计。
